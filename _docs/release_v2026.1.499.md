# Primitive 2026.1.499

Exchange adds `ResolveIP(ctx, ResolveIPRequest{Host})`. Host is a letter-digit-hyphen DNS name of at most 253 bytes with 1..63 byte labels, no trailing dot and a final label that is not all digits, so IP literals, legacy numeric forms, ports, URLs and underscores are refused with `core.ErrExchangeContract` before any lookup. The lookup is `net.DefaultResolver.LookupNetIP(ctx, "ip", host)`. Results are unmapped, zone-free, distinct, in resolver order and between one and sixteen; more than sixteen distinct addresses, an invalid address or an empty answer is refused with `core.ErrExchangeResponse` rather than clipped. Native lookup failures keep their `*net.DNSError` beside `core.ErrExchangeTransport`. Context validation follows `DialTCP`. No caching, retry, server selection or address admission policy; deciding which addresses a caller may dial stays with the caller.
