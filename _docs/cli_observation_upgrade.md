# Native CLI observations

Primitive observes effective Unix user labels through the native effective uid
and account database, without PATH or cached real-user identity. Windows and
other platforms return typed Unsupported until native implementations are proved.

Go-toolchain capabilities now observe the native installation directory and
download one exact canonical module version. Completed process stdout is streamed
to borrowed native scratch, whose observed extent must agree with the completed
process receipt. Native exit observations and filesystem/context causes remain
inspectable. The returned module directory is bound to the requested module and
version. Scope and cleanup failures return no fact. JSON uses the native v2
reader; its scalar and whitespace allocation issue remains open. Scratch grows
with output bytes. Other compiler metadata buffers and package worlds are not
closed by these narrow APIs.

Furnace proof lives under `/data/evidence/raw/primitive/2026-10-12-cli-native`.
Hostfacts and Go-toolchain race suites passed 2,492 terminal events, with no
failure or skip. Additional real process fixtures passed ten terminal events:
output past the former probe ceiling, one-byte configured output budgets,
coordinate mismatch, native exit, null fields and permission refusal. Actual
cmd/go installation and offline module-cache observations are separately proved.
Earlier failed oracle execution is retained. Semantic fuzz and deliberate
mutations bind the admission and streaming claims. Independent acceptance belongs
to the user; global lint/Hammer and remaining package migrations remain open.
