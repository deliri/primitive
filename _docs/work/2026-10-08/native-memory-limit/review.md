Primitive executes one validated Go soft-memory-limit operation through runtime/debug.SetMemoryLimit. The caller owns the budget, pressure threshold, monitoring and response. Typed previous/applied byte counts describe this synchronous operation; they do not promise a hard ceiling or the absence of later concurrent settings.

Zero and values exceeding Go's signed runtime range are refused before mutation. Nil and cancelled contexts preserve their identities and leave the runtime setting unchanged. Native tests observe the actual runtime setting, preserve the prior setting, and restore it. A semantic fuzz oracle applies mutated requests and compares the actual native result with the independently computed signed range and prior limit.
